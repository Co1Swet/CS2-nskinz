>

## 中文说明

v0.6.0-beta 完成五槽位枪械贴纸自定义位置的首个公开测试版。预设模式仍为默认值并保留 Demo 已记录的数据；启用自定义位置后，可调整磨损、缩放、旋转、相对槽位材质基准的 offset X／Y 增量与 schema。二维画布显示当前具体枪械的枪口朝左轮廓、五个贴纸的相对位置，选中槽位为黄色，其它已配置槽位为白色；“游戏内实时预览”会以节流频率把调整同步到当前生成 Demo。

预览和写入现共用从当前 CS2 VMDL/VMAT 数据生成的投影与逆投影。画布使用 `material base + stored delta` 显示实际位置，拖拽时再减去材质基准写回 Econ 增量，解决基准被重复叠加、X／Y 方向相反以及不同枪型移动倍率不一致的问题。若源槽位没有现代 offset/schema 节点，请先生成一次临时换肤 Demo，让重写器补齐完整字段。

默认 CT／T 手套视觉刷新已迁移到 2026-10-08 的当前 CS2 客户端。重写器生成的 definition、paint、seed、wear、item identity 与 bodygroup 数据原本已正确，本次更新重新验证并更新原生刷新回调、HUD 消费者与实体标识根节点，因此默认 CT 手套不再停留在网络字段正确但画面未刷新的状态。

`de_mirage_water` 不再使用大范围暗区推断。DLL 只内嵌用户确认的 `720×720` Alpha 基准，逐像素复现其透明轮廓和抗锯齿边缘；RGB 继续取自本机安装的工坊纹理，不在发布包中重复分发地图美术资源。中央、右侧及下方的合法空洞保持透明。通用“暗色道路恢复半径”不会影响这张已核验地图，避免把合法空洞误填成道路。

### 使用方法

1. 选择枪械和贴纸槽位。保持“预设位置”即可沿用原 Demo 或枪械原生位置；需要移动时启用自定义位置。
2. 在枪械轮廓画布拖动选中贴纸，或微调 offset X／Y、缩放和旋转。最终效果以游戏画面为准。
3. 若该槽位尚不存在，或缺少 offset/schema，先使用“临时换肤 Demo”生成并加载一次，再开启“游戏内实时预览”。
4. 默认 CT／T 手套也应通过临时 Demo 重建后重新加载。升级 DLL 前必须完全退出 CS2/HLAE，避免旧模块仍驻留内存。
5. 更换到 `de_mirage_water` 时点击“更新”重新生成雷达覆盖，再第二次加载同一 Demo。默认背景不透明度 `0%` 时，透明轮廓与内置基准完全一致。

## English notes

v0.6.0-beta is the first public build of custom placement for all five firearm sticker slots. Preset mode remains the default and preserves recorded demo data. Custom mode edits wear, scale, rotation, per-slot offset X/Y deltas and schema. The two-dimensional editor shows the exact muzzle-left silhouette of the selected firearm and the relative location of all five slots; the selected sticker is yellow and configured peers are white. Optional live preview publishes throttled edits to the loaded generated demo.

Preview and serialization now share projection/inverse-projection data generated from current CS2 VMDL/VMAT assets. The canvas displays `material base + stored delta`, while dragging subtracts the material base before writing the Econ delta. This fixes the former double-applied base, reversed axes and per-weapon movement-rate mismatch. Generate a Temporary Demo once when a source slot lacks modern offset/schema nodes.

The guarded stock CT/T glove visual refresh is rebased on the current 2026-10-08 CS2 client. Generated-demo definition, paint, seed, wear, item identity and bodygroup fields were already verified; this build updates the byte-verified native refresh callback, HUD consumer and entity-identity root so correct stock-glove fields can reach the rendered client state.

`de_mirage_water` no longer guesses large enclosed dark regions. The DLL embeds only the approved `720×720` alpha reference and reproduces its transparent outline and antialiased edges exactly; RGB remains sourced from the locally installed Workshop texture, so the release does not redistribute the map artwork. Legitimate central, right-side and lower voids remain transparent. The generic dark-road radius intentionally does not modify this audited map.
