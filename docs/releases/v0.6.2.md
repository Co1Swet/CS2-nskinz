## 中文说明

v0.6.2 将全部依赖 CS2 内部地址的路径迁移到 2026-10-22 客户端 `2000935`。本次不是只放宽版本门禁：刀具序列化、模型设置、材质复制／生成、资源重收集、骨架引用、weapon-type 动画图、手臂生命周期、默认手套视觉刷新、HUD 消费者和实体根节点均按今日 DLL 重新定位，并继续用 PE 时间戳、精确调用目标、RIP 指令窗和唯一签名匹配保护。任一证据不成立时，对应原生路径会拒绝执行。

默认 T／CT 原皮手套修复被保留并在新版本上重新验证。临时 Demo 会直接写入 Pawn `m_EconGloves` 的目标定义、paint kit、品质、身份字段、变更计数及两组 bodygroup。对完整匹配请求的生成 Demo，运行时直接接受序列化结果，不再执行会互相覆盖的第二次实时 ItemView 写入或 HUD 刷新。源 Demo 中可读但 definition=0 的默认空槽严格保持为“仅 Demo 重写”，不创建或镜像实时 `CEconWearable`，避免已由崩溃转储确认的旧 Pawn 销毁访问冲突。重写器还会把有涂装手套的 `quality=0` 规范化为 `3`，同时按 Pawn 的 `m_iTeamNum` 分别应用 T／CT 规则。

今日更新还改变了 CS2 原生雷达编译器的启动依赖：`resourcecompiler.exe` 会强制挂载 `core/pak01_dir.vpk`。旧版隔离缓存只挂接 shader VPK，因此会直接报缺少文件。v0.6.2 会把安装目录中的 `pak01_dir.vpk` 目录索引只读硬链接到隔离缓存，并把其大小／时间纳入环境指纹；不会复制几十 GB 的 VPK 数据，也不会修改 CS2 或工坊文件。37 个本机工坊地图条目和各专用雷达遮罩已重新回归，原生 VTEX 输出包含有效 `RED2` 与 `DATA` 块。

枪械涂装、五槽贴纸、贴纸自由位置与滑轨、具体枪型轮廓预览、刀型替换、挂件已有模块修改、地图替换和任意字段数量 Demo 重写均保持完整。今日 `items_game.txt`／中文本地化从已安装 VPK 重新提取；目录结果为 1,408 个枪械涂装、74 个手套涂装、11,642 张贴纸、144 个挂件和 15 种品质。

### 使用与升级

1. 完全退出 CS2 与 HLAE，确保旧 DLL 不再驻留。
2. 使用 HLAE `2.192.8`，以 `-insecure` 启动离线 Demo 环境。
3. 只加载一个语言版本：`Lyan_nskinz-v0.6.2-EN.dll` 或 `Lyan_nskinz-v0.6.2-zh-CN.dll`。
4. 默认 T／CT 手套、原皮枪械、缺失贴纸槽或刀型需要新增字段时，第一次播放源 Demo 后配置并点击“更新”，再到“临时换肤 Demo”生成第二个 Demo。
5. 游戏再次更新并出现版本／指令窗不匹配时，请停止使用对应模块并提交两份日志，不要绕过保护检查。

## English notes

v0.6.2 rebases every client-address-dependent path on the October 22, 2026 CS2 `2000935` client. This is not a version-gate-only change: knife serialization, model assignment, material copy/generation, resource recollection, skeleton references, weapon-type animation graphs, arms lifecycle, stock-glove refresh, HUD consumers and entity roots were relocated from the installed binaries. Each path remains fail-closed behind PE identity, exact call targets, RIP-relative instruction windows and unique signature matches.

The stock/default T and CT glove repair is preserved. Temporary Demo materializes the complete Pawn `m_EconGloves` item, including definition, paint kit, quality, identity, change counter and both bodygroup fields. A generated carrier that exactly matches the request is authoritative, so runtime does not apply a conflicting second ItemView write or HUD refresh. A readable definition-zero source slot is rewrite-only and never receives a runtime-owned ItemView or mirrored `CEconWearable`, preventing the captured old-Pawn destruction crash. Painted gloves normalize `quality=0` to `3`, and T/CT rules are selected from each Pawn's `m_iTeamNum`.

The current CS2 `resourcecompiler` also requires `core/pak01_dir.vpk` during startup. v0.6.2 read-only hard-links the installed directory indexes into its cache-isolated compiler environment and incorporates their metadata into the cache fingerprint. It neither copies the multi-gigabyte archives nor edits game/Workshop files. All 37 installed Workshop entries and the map-specific radar masks were rerun; native VTEX outputs validate their `RED2` and `DATA` blocks.

All existing firearm finishes, five sticker slots, custom placement/sliders, exact weapon preview, knife models, existing keychain-module changes, map replacement and arbitrary-field-count Demo rewriting remain available. The installed catalog resolves to 1,408 weapon finishes, 74 glove finishes, 11,642 stickers, 144 keychains and 15 qualities.
