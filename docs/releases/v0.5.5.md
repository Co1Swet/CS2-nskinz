## 中文说明

v0.5.5 修复 CS2 2000922 更新后的手套视觉刷新 ABI：同步迁移原生刷新入口、HUD consumer、客户端专用实体块根地址和全部七处机器码证据窗。只有当前安装的 `client.dll` 完整匹配这些证据时才会安装手套 Hook。

临时换肤 Demo 不再跳过源 Demo 中已经带涂装的枪械和手套。重写器会复用已有 paint／seed／wear 属性槽，仅追加确实缺失的槽位，并保持原网络向量长度。源 Demo 中没有对应 XUID 的配置会安全跳过，不再让整个重写任务失败。

此前生成 Demo 卡在“正在调整准星”或“子弹收集中”等加载进度阶段，根因是实体字段增长后，包内 `serialized_entities` 逐实体位长度表仍保留旧值。现在 writer 会保留字段路径位编码、记录每条实体的位长度增量并同步更新长度表；生成文件会重新解析验证后才返回成功。

枪械现在支持“已有贴纸原位换图案”：只替换源 Demo 已存在逻辑槽位的贴纸 kit ID，保留原磨损、缩放、旋转和 CS2 自由摆放数据。缺失槽位不会创建。普通枪械的临时 Demo 重建还会统一根据目录写入 legacy／modern `mesh_group_mask`，避免皮肤套用错误网格；刀具重建路径不参与该逻辑。

`de_mirage_water` 的雷达暗色道路宽于通用恢复半径。本版只对该雷达使用现有算法的 32 像素安全上限，恢复两侧均有可信道路边界的暗色跨度，不做外部底色膨胀。

## English notes

v0.5.5 updates the glove visual-refresh ABI for CS2 2000922. The native refresh entry, HUD consumer, client-only entity chunk root and all seven machine-code evidence windows were migrated. Glove hooks are installed only when the current `client.dll` matches the complete evidence set.

Temporary Demo no longer bypasses firearms and gloves that already have paint in the source demo. The rewriter reuses existing paint/seed/wear attribute slots, appends only missing slots without shrinking the network vector, and safely skips configured XUIDs that are absent from the source demo.

Generated demos could previously stall during loading because entity field growth was not reflected in the packet's per-entry `serialized_entities` bit-length table. The writer now preserves field-path bit encoding, records each entity's bit-length delta, synchronizes the length table and parses the generated output again before reporting success.

Firearms now support existing-sticker image replacement. Only the kit ID of a logical slot already recorded in the source demo is changed; wear, scale, rotation and CS2 free-placement data are preserved. Missing slots are not created. Every rebuilt standard firearm also serializes the catalog-verified legacy/modern `mesh_group_mask`, while knife routing remains separate and unchanged.

The `de_mirage_water` radar contains legitimate dark roads wider than the generic recovery radius. This release applies the existing bounded recovery algorithm's safe 32-pixel maximum only to that radar, restoring spans bounded by trusted road pixels without dilating the outside matte.

Targeted installed-client glove and firearm-material evidence, Temporary Demo rewriting, radar recovery and both Rust writer layers pass. Rendered acceptance remains specific to the source demo and Workshop map combination.
