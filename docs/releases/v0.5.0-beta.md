# v0.5.0 Beta — 刀模、动作与默认手套测试版 / Knife, animation and stock-glove beta

Release date / 发布日期：2026-09-15

## 简体中文

### 定位

这是供 HLAE 离线 Demo 回放验证的 **v0.5.0 测试版**。枪械皮肤继续沿用 v0.4.5 已验证的原路径；当前测试重点是播放 Demo 后再修改刀模、刀动作及 T/CT 默认手套，而不是预先改写 Demo 文件。

本版本不使用 CS2 Insight Engine 的文件改写器，也不会修改 `.dem`。所有外观修改均由 DLL 在 HLAE 已加载 Demo 的 CS2 进程中完成。

### 本次代码状态

- 默认手套同时覆盖库存与可穿戴实体入口，并按玩家 pawn 缓存 HUD/第一人称消费者，减少重建期间绑定到错误对象。
- T/CT 默认 `m_EconGloves` 路径先使用 CS2 原生 `CEconItemAttribute` 追加入口构造涂装 `6`、seed `7`、wear `8`，确认完整成功后才提交物品定义和初始化字段。
- 手套事务任何步骤失败都会恢复原物品定义、账号、品质、回退字段、初始化状态和属性向量，避免把半初始化物品视图留给 Source 2；这是针对 `tier0.dll` 访问异常闪退的修正。
- 刀实体在 Demo 重载、实体代际变化和 `BeforeWeapon` 接管时保留刀模/动画监听器；武器位置与 HUD 消费者分开处理，降低刀模占用手枪位置、手枪检视动作或原皮匕首动作残留的概率。
- DLL 文件名、控制面板标题和首条启动日志均带 `v0.5.0-beta`，便于从测试日志确认实际加载版本。

### 文件与加载

- `Lyan_nskinz v0.5.0-beta EN.dll`：英文界面。
- `Lyan_nskinz v0.5.0-beta zh-CN.dll`：简体中文界面和中文目录名称。
- `Lyan_nskinz-v0.5.0-beta-CS2-2000908-windows-x64.zip`：双语 DLL、游戏版本说明和 SHA-256。

中文 DLL 示例：

```text
mirv_loadlibrary "D:\nSkinzCS2-v0.5.0-beta\Lyan_nskinz v0.5.0-beta zh-CN.dll"
```

英文 DLL 示例：

```text
mirv_loadlibrary "D:\nSkinzCS2-v0.5.0-beta\Lyan_nskinz v0.5.0-beta EN.dll"
```

先完全退出已加载旧 DLL 的 CS2/HLAE，再启动 HLAE `-insecure`、打开 Demo，并且只加载一个语言版本。DLL 必须先从 ZIP 解压到可写文件夹；不要把 `mirv_loadlibrary` 指向 ZIP。

### 测试版验证边界

- 发布前要求完整原生测试、当前 `client.dll`/`animationsystem.dll` 只读绑定检查、DLL 依赖审计及中英文隔离加载通过。
- 枪械路径为沿用的稳定实现，本轮没有改为 Insight Engine 的文件写入逻辑。
- 刀模和默认手套属于测试功能。自动化只能证明事务、回滚、实体生命周期和已知二进制入口符合预期，不能替代具体 Demo 中的画面验收。
- 测试时请分别记录：重新加载 Demo 后首次切刀、连续切枪/切刀、检视、暂停/跳 tick、T/CT 默认手套，以及 `nSkinzCS2.log` 中的版本行、glove/knife apply 结果与失败原因。

**只用于 HLAE `-insecure` 离线 Demo。禁止用于 VAC 保护或任何在线服务器。**

## English

### Scope

This is the **v0.5.0 beta** for HLAE offline-demo validation. Firearm finishes retain the proven v0.4.5 runtime path. The beta focus is applying knife models/animations and stock T/CT gloves after a demo is already open; no `.dem` file rewriting is used.

The default-glove transaction now constructs engine-owned paint, seed and wear attributes before committing item-view identity fields, with complete rollback on every partial failure. Knife lifecycle adoption preserves model/animation listeners and separates weapon/HUD consumers to address pistol-slot placement and stale pistol/original-dagger actions after demo reloads.

Compatibility is limited to the checked baseline listed above: Windows x64, HLAE 2.191.1, CS2 Steam Build 25218825, Client/Server 2000908, Patch 1.41.8.1, Source revision 10981323, dated Sep 09 2026 15:23:58.

Use exactly one extracted language DLL in a writable folder and load it only in an HLAE `-insecure` offline-demo process. Knife and stock-glove rendering remain beta acceptance items even when all automated and loader gates pass.
