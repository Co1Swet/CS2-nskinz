# nSkinzCS2 v0.4.3 — 枪械涂装兼容修复 / Gun finish compatibility

Released: 2026-08-31 · Windows x64 · English / 简体中文

## 简体中文

### 本次更新

- 修复 M4A4 从「破浪狂飙」换为「皇帝」却显示原皮的问题：按目标涂装的 `use_legacy_model` 元数据选择网格，并同步世界枪身与经过归属验证的第一人称枪身。皇帝 844 使用旧网格 2，破浪狂飙 1353 使用新网格 1。
- 修复高位 HUD 手臂不在网络实体缓存时漏查第一人称枪身的问题。按明确句柄查询单个槽位，再检查完整句柄、归属和场景关系；不扩大扫描范围。应存在但未解析到的活动 HUD 会在任何外观写入前保持等待。
- 枪械涂装按精确枪型兼容关系筛选。面板、旧配置和实际运行时写入统一校验；不兼容项保留原选择并标为不可用，缺失兼容数据时拒绝应用，不会静默变为原皮。共享涂装、「不修改」和「原皮」选项保留，完整目录没有删减。
- 发布前复查补上枪械刷新缓存的实体代际校验：完整句柄、实体/身份对象地址与创建 tick，以及世界/第一人称渲染对象变化。新对象不复用旧刷新记录；稳定对象、收枪/暂时没有 HUD、重复修复回放字段不触发重复刷新。只影响标准枪械链，不修改刀饰面和手套刷新策略。
- 保留独立面板的中文输入法/英文搜索崩溃修复，以及 `/MT` 静态运行库和内嵌着色器。除 Windows、CS2、HLAE 外，无需另装 VC++、旧版 DirectX、.NET、Python 或编译器。
- 包含已保存的独立刀模源码与测试框架；生产适配器仍只读，饰面与模型请求分离。**本版不宣称换刀模、切刀/检视动作或穿模问题已经解决。**

### 下载与使用

- `nSkinzCS2.dll`：英文版；`nSkinzCS2.zh-CN.dll`：简体中文版。
- `nSkinzCS2-v0.4.3-windows-x64.zip`：中英文 DLL、加载说明、发布说明。
- `nSkinzCS2-v0.4.3-source.zip`：与发布提交对应的源码，不含私人配置、日志、Demo、游戏资源或实测截图。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

备份配置并退出旧版 HLAE/CS2，将 DLL 解压到可写目录，重新通过 HLAE 带 `-insecure` 打开离线 Demo。每次只加载一个语言版本，不叠加新旧 DLL。以下指令要求文件实际位于 D 盘根目录：

```text
mirv_loadlibrary D:\nSkinzCS2.zh-CN.dll
```

英文版改为 `nSkinzCS2.dll`。有空格的路径只使用一对英文半角双引号。按 `Insert` 打开面板，配置后点击“更新”。目录/配置/日志自动生成。**仅用于 HLAE `-insecure` 离线 Demo，禁止用于 VAC 或联机服务器。**

### 验证范围与已知限制

- 用户已确认本地 Demo 的皇帝修复成功。发布前增加的实体代际保护完成了后台回归，未另做新一轮游戏画面或整段 FPS 测试。
- 45 项原生回归、8 个涂装定向检查通过；真实游戏目录覆盖 34 枪型、1,449 个合法组合，均有明确新旧网格元数据且没有重复 ID。完整目录仍含 1,408 项武器涂装、74 项手套涂装。
- 生产 HUD 查找测试覆盖高位槽位、错误 serial/owner、歧义与休眠武器共存；缺失 HUD 在写入前等待。缓存测试覆盖槽位复用、创建 tick/地址变化、渲染对象重建、1,000 次稳定轮询和不完整读取，不影响无关缓存。
- 双语构建、中文界面/皮肤名称、UTF-8、导入依赖审计通过；6 个隔离加载用例及无窗口 WARP/ImGui 像素回读、三次资源重建通过。不是独立纯净 Windows 虚拟机测试。
- 本轮范围内未发现其他未处理的、已确认的同类枪械缺陷；**不能保证所有武器、涂装、Demo 和未来 CS2 版本零漏洞**。目录合法性不等于逐个涂装的画面认证。
- 刀原皮第一人称旧材质残留、未完成的独立刀模/动画链，以及空挂件模块创建仍有既有局限。

## English

### Changes

- Fixed modern/legacy gun mesh selection from target paint metadata, including M4A4 Full Throttle (1353, modern mesh 1) → The Emperor (844, legacy mesh 2). Synchronize the world and ownership-verified first-person render consumers.
- Resolve the explicit HUD-arms handle even outside the network-entity cache, with full-handle, ownership and scene checks. An expected but unresolved active HUD defers all appearance writes; no broad entity scan was added.
- Filter gun finishes by exact installed-game weapon/paint pairs. Runtime writes and imported configs use the same validation. Invalid selections remain visible as unavailable; unknown data fails closed. Shared finishes, No Change and explicit Vanilla remain, and the complete catalog is preserved.
- Added gun-only refresh generation tracking for carrier/render identities, full handles, object addresses and creation ticks. Recreated objects cannot inherit completed refreshes; stable bindings, temporarily hidden HUDs and replicated-field repair do not repeatedly regenerate materials. Knife-finish and glove refresh policies are unchanged by this guard.
- Retained isolated-panel IME/English-search crash fixes, static MSVC `/MT` and embedded shaders. No extra redistributable, legacy DirectX, .NET, Python or compiler installation beyond Windows, CS2 and HLAE.
- Includes saved independent knife-model source/tests. Its production adapter remains read-only and model requests are separate from finish requests. Model replacement, draw/inspect animations and clipping are **not** claimed complete.

### Installation and validation

Choose one language DLL or extract the Windows x64 ZIP into a writable folder. Back up your config, restart HLAE/CS2, launch an offline demo through HLAE with `-insecure`, and load one DLL only:

```text
mirv_loadlibrary D:\nSkinzCS2.dll
```

Use the real full path; quote a spaced path exactly once with ASCII quotes. Press `Insert`, configure the panel and click `Update`. Never use on VAC/online servers. The source ZIP matches the release commit; private logs, configs, game assets, demos and gameplay screenshots are excluded. Verify downloads with `SHA256SUMS.txt`.

The user confirmed the Emperor fix in their local demo. The subsequent generation guard passed background regression, without a new gameplay/FPS run. All 45 native regressions, 8 targeted checks and both builds passed. Real catalog coverage is 34 guns / 1,449 unique valid pairs, each with explicit modern/legacy metadata; the complete catalog retains 1,408 weapon paints and 74 glove paints. Tests exercise the production HUD walker/pending gate, object recreation, 1,000 stable polls and partial reads. Six isolated loader cases, headless WARP/ImGui readback with three resource recreations, localized text and import audits passed. This is not an independent clean-Windows VM test.

No additional confirmed, unhandled gun defect of these reviewed classes was found. This is not a guarantee of zero bugs or visual coverage of every skin/demo. Existing vanilla-knife material, unfinished knife-model/animation and missing-keychain-module limitations remain.
