## 中文说明

v0.5.8 记录并发布当前贴纸阶段：已有槽位继续只替换贴纸图案 ID，保留源 Demo 中的磨损、缩放、旋转以及 CS2 自由摆放数据；源 Demo 中不存在的请求槽位，现在可由“临时换肤 Demo”补建到该枪械的原生预设位置。

补建槽位会写入一组完整的 legacy Econ 动态属性：贴纸 ID、磨损、缩放和旋转。属性分配与枪械涂装字段共用同一个索引规划器，可避开 paint kit／seed／wear 节点，并同步扩展动态属性计数。写出后，重写器会重新解析生成的 Demo，逐一确认每个请求槽位都存在且贴纸 ID 精确匹配；任何缺失都会阻止自动加载。原 Demo 始终不会被覆盖。

本版本**暂不增加自由摆放功能**：不会为新槽位创建或修改 offset X／Y、schema 等现代自由摆放字段。新建贴纸使用枪械原生预设位置；源 Demo 已有的自由摆放字段则原样保留。实时“更新”路径仍只支持已有槽位，补建缺失槽位必须使用“临时换肤 Demo”。

### 操作方法

1. 在枪械贴纸列表中选择一个逻辑槽位和目标贴纸图案；可按需要设置磨损、缩放和旋转，缺失槽位会使用这些值创建。
2. 已有槽位若只需原位换图案，可点击“更新”；其原有变换和自由摆放数据不会改变。
3. 若源 Demo 没有该槽位，打开“临时换肤 Demo”，点击“一键生成并加载临时 Demo”。成功日志会分别报告替换和创建的贴纸槽数量。
4. 如重写器无法完整验证所有请求槽位，输出不会进入自动 `playdemo` 队列；请保留错误日志和脱敏后的 Demo 信息用于排查。

## English notes

v0.5.8 publishes the current sticker milestone. Existing logical slots still change only the sticker kit ID, preserving the source demo's wear, scale, rotation and CS2 free-placement data. A requested slot absent from the source demo can now be materialized by the Temporary Demo workflow at the firearm's native preset position.

A created slot receives the complete legacy Econ attribute group: sticker ID, wear, scale and rotation. Sticker and firearm paint fields share one dynamic-attribute allocator, so newly appended nodes do not collide with paint kit, seed or wear. The vector count is updated once, and the written demo is reparsed to verify that every requested slot exists with the exact requested kit before playback is queued. The source demo is never overwritten.

This release deliberately does **not** add free placement. It does not create or edit modern offset X/Y or schema attributes for new slots. Existing free-placement attributes are preserved byte-for-byte; newly created stickers use the weapon's native preset location. Live Update remains limited to existing slots, while missing slots require Temporary Demo generation.

### Usage

1. Select a logical sticker slot and target kit in the firearm sticker list. Wear, scale and rotation are used when a missing slot is created.
2. For an existing sticker, press Update to replace its image in place; the recorded transform and free placement remain unchanged.
3. If the source demo lacks that slot, open Temporary Demo and press Generate and load temporary demo. The result reports replaced and created slot counts separately.
4. If the rewriter cannot verify every requested slot, the output is not queued for `playdemo`; retain the error log and redacted demo details for diagnosis.
