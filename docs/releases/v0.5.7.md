## 中文说明

v0.5.7 修复部分新工坊地图在 `mirv_pov` 下雷达透明区域显示为不透明黑色圆底的问题。本次用实际已安装的 `INFERNO REFORGED` 工坊项目（`3802103572 / de_inferno_d`）复现：它的 1024×1024 雷达解码后有 `742805` 个透明像素，旧逻辑因此误判为“已有可用透明度”并跳过覆盖生成，但工坊打包的 VTEX 资源表示与 Panorama / `mirv_pov` 实际混合结果并不等价。

现在，只要工坊雷达含有大量源 Alpha，nSkinzCS2 就会保留其 RGBA 像素，再通过现有的独立缓存路径编译为已知可用的 CS2 原生 BC7 VTEX，不再因解码结果有 Alpha 就直接返回 `NotNeeded`。这一路径不修改工坊、CS2 或 Demo 原文件，并使用内容寻址别名避免 Panorama 复用旧缓存。

黑色圆底还有第二层原因：CS2 Panorama 有独立的 `cl_hud_radar_background_alpha` 背景层。之前面板中的“已识别黑底的不透明度”只处理雷达纹理像素，对这个 HUD 层无效。v0.5.7 会在 `FRAME_RENDER_PASS` 安全阶段同步该 CVar：面板为 `0%` 时同时设置 `cl_hud_radar_background_alpha 0.000`，不会覆盖现有的 `playdemo` 自动化命令。

## English notes

v0.5.7 fixes Workshop-map radar transparency that could still render as an opaque black circle under `mirv_pov`. The issue was reproduced with the installed `INFERNO REFORGED` Workshop item (`3802103572 / de_inferno_d`). Its 1024×1024 overview decodes to `742805` transparent pixels, so the old path classified it as already transparent and skipped overlay generation. Decoded alpha alone does not guarantee that the Workshop-packaged VTEX representation and Panorama / `mirv_pov` blending path will render it correctly.

Workshop radars with substantial source alpha are now preserved and recompiled through the same known-good, cache-isolated CS2-native BC7 VTEX path used by generated masks. This normalizes the resource representation without editing the Workshop item, CS2 files, or the demo. Content-addressed aliases continue to prevent Panorama from reusing stale compiled texture data.

There is also a separate Panorama background layer controlled by `cl_hud_radar_background_alpha`. The existing classified-background opacity control previously affected only radar texture pixels. v0.5.7 synchronizes that CVar from `FRAME_RENDER_PASS`; a UI value of `0%` also dispatches `cl_hud_radar_background_alpha 0.000` without replacing the independent `playdemo` automation queue.

The installed Inferno Reforged regression now returns `Generated` instead of `NotNeeded`, preserving `305771` visible pixels and `742805` transparent pixels. Its normalized PNG compiles successfully through the current CS2 `resourcecompiler.exe` into a valid native VTEX. The full native suite and existing installed Workshop radar cases pass, as do both language builds, isolated loader scenarios and the headless WARP render gate. Final rendered acceptance still requires a full HLAE/CS2 restart and a second `playdemo` of the same demo.
