# nSkinzCS2 v0.6.5 — Synchronize knife killfeed identities

Release date / 发布日期：2026-10-27

## 中文说明

修复临时 Demo 已更换刀型，但右上角击杀信息仍显示原刀型的问题。旧版只重建刀实体，未同步死亡事件；本版在离线重建时同时修改目标玩家刀杀事件中的刀名和物品身份。

- 按击杀发生时的攻击者 XUID 和 T／CT 队伍匹配刀配置，处理连续多条刀杀。
- 动态读取事件描述表中的 ID、字段顺序与类型；核对全部 22 个支持刀型的事件名，包括资源文件名与事件名不同的 M9、鲍伊、折刀和锯齿爪刀。
- 同步 `weapon`、存在的 `weapon_itemid` 和 `weapon_fauxitemid`，使事件与重建刀实体保持一致。
- 保留普通枪杀、未配置玩家刀杀、受害者、助攻、爆头、穿烟、击杀时间及顺序；保留未知 protobuf 扩展字段。
- 写出后重新解析死亡事件，核对数量、tick 和完整预期内容；结果详情显示匹配、实际修改和读回验证计数。
- 所有新增工作在临时 Demo 离线重建及验证阶段执行，不增加播放期间的实时 HUD Hook、每帧扫描或刷新。

保留 v0.6.4 的挂件临时 Demo 替换／新增／清除、默认 T／CT 手套重建、枪皮、五槽自定义贴纸及工坊地图／雷达功能。默认手套和挂件继续使用已有的临时 Demo 路径。

### 验证与边界

- Rust 常规测试：22 通过；另显式运行真实录制刀杀专项测试。
- 两份真实 Demo 共 262 条死亡事件：9 条目标刀杀完成同步，253 条其它记录保持原样，包含 5 条未配置玩家刀杀；18 次正反向跳转读回一致。
- 相同输入与配置对比旧、新重写器：旧版刀实体已是爪子刀，但事件仍为默认 T 刀；修复版同步了刀名与物品身份。
- 刀、枪皮、五槽贴纸、默认 T／CT 手套和挂件混合请求通过，128 条死亡事件读回通过，原有手套／挂件逐记录验证通过。
- 完整 C++ 回归、中英文 DLL 隔离加载、便携依赖、中文文本及离屏 WARP 渲染检查通过。

**以上为离线数据、跳转读回和 DLL 加载验证，实际 CS2/HLAE 击杀图标画面仍待验收。** 本次没有新的游戏内帧时间基准，也未对所有来源 Demo、控制器更换或机器人接管进行现场认证。

详见[根因、产物对比与回归记录](https://github.com/Lyan-edit/CS2-nskinz/blob/v0.6.5/docs/development/knife-killfeed-demo-rewrite-20261027.md)。

### 升级步骤

1. 退出 CS2／HLAE，备份需要的配置；重新启动后只加载一个语言版本的 v0.6.5 DLL。
2. 打开**原始 Demo**，设置该录制中目标玩家的 XUID、队伍和目标刀型，并应用配置。
3. 点击“生成并加载临时 Demo”。已有旧临时 Demo 不会因更换 DLL 自动修正，只点击“更新”也不会重写旧文件。
4. 回放目标刀杀并检查右上角图标；修改刀型后重新生成临时 Demo。

兼容基线延续 v0.6.4：CS2 Client/Server `2000935`、Patch `1.41.9.2`、Steam Build `26144732`；HLAE `2.192.8`／AfxHookSource2 `0.41.8`。本版是击杀信息同步修复，不声称适配新的客户端更新。

## English notes

Fixed Temporary Demo knife reconstruction leaving the original knife identity in the killfeed. The rewriter now updates the configured attacker's knife death events alongside the knife entity.

Rules resolve the attacker and team at the event position. Event IDs, key ordering and types come from the Demo descriptor table. All 22 supported knife event names were checked, including model/event-name aliases. The weapon token and available item/faux-item identities are synchronized; other players, firearm kills, assists, flags, event timing/order and unknown protobuf fields are preserved.

An independent output pass verifies the expected death records. All new work runs during offline reconstruction and verification, with no new live HUD hook or per-frame scan. Existing keychain reconstruction, default T/CT gloves, firearms, five-slot custom stickers and Workshop map/radar features remain available.

Two real recordings passed: 262 death events, 9 target knife deaths synchronized, 253 other records preserved including 5 unconfigured knife kills, and 18 forward/backward seek readbacks. Old/new output comparison, a mixed knife/firearm/sticker/T-CT-glove/keychain request, 22 regular Rust tests, the full C++ suite and both DLL loading/offscreen gates passed. **Rendered CS2/HLAE killfeed icons still require in-game acceptance.** This is not a new gameplay performance benchmark or exhaustive validation of controller changes and bot takeover.

Restart CS2/HLAE, load one v0.6.5 DLL and regenerate the Temporary Demo **from the original recording** after configuring the target player's knife. Replacing the DLL or pressing Update does not repair an existing generated file.

The compatibility baseline remains CS2 `2000935` / Patch `1.41.9.2` / Steam Build `26144732`, HLAE `2.192.8` / AfxHookSource2 `0.41.8`.
