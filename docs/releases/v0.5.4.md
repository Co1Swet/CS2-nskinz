## 中文说明

v0.5.4 保留混合换肤规则：已有网络涂装的枪械和手套继续走原实时逻辑；无涂装的默认枪械、T/CT 默认手套 `5028`/`5029` 及 T/CT 默认匕首 `59`/`42` 在新临时 Demo 中重建必要字段。原 Demo 始终只读，不会被覆盖。

目标刀动画骨骼不要求存在于源 Demo。重写器从本机已安装 CS2 的松散内容或 `pak01_dir.vpk` 验证目标编译骨骼，然后写入标准 `AnimAssetData` 加载元数据。枪械、刀和手套支持名称标签；未填写自定义名称时使用 `nSkinz CS2`。

本版修复了 CS2 2000919 下原皮 AK-47 已显示新 HUD 项目、但第一人称模型仍保持原皮的问题。运行时现在严格验证 2000919 新增重定位指令后的材质生成入口，每个实体代际仅调用一次引擎原生材质初始化，并复用稳定缓存，避免逐帧刷新造成卡顿。

## English notes

v0.5.4 retains hybrid cosmetic routing: already-painted firearms and gloves stay on the established live path; stock firearms, default T/CT gloves (`5028`/`5029`) and default T/CT knives (`59`/`42`) are materialized in the generated demo before its second playback. The source demo remains read-only and is never overwritten.

Target knife animation skeletons no longer need to exist in the source demo. The rewriter validates the compiled target skeleton in installed CS2 loose content or `pak01_dir.vpk`, then writes the standard `AnimAssetData` loader metadata. Firearms, knives and gloves support name tags; an empty custom value uses `nSkinz CS2`.

This release fixes the stock AK-47 case on CS2 2000919 where the HUD identity changed but the first-person model remained unpainted. The runtime now strictly verifies the updated material-generator entry with its added relocation instruction, performs engine-owned material initialization once per entity generation, and reuses stable cached state instead of refreshing it every frame.

Targeted installed-client weapon-material evidence, temporary-demo cosmetic rewriting and isolated bilingual loader/render gates pass. Rendered acceptance for map models/radars, knife models/actions and stock carriers remains specific to each demo and Workshop-map combination.
