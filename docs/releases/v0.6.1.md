## 中文说明

v0.6.1 将全部需要客户端内部地址的功能迁移到 2026-10-14 的 CS2 `2000932`。本次更新移动了刀具模型／动画／材质链以及默认手套原生视觉刷新链；发布版已重新定位并校验刀具序列化路由、模型设置、材质复制与生成、资源重收集、骨架引用、weapon-type 动画图、手臂生命周期、默认手套刷新回调、HUD 消费者及实体根节点。所有入口在启用前仍会检查当前 PE 时间戳、精确调用目标和 RIP 指令窗，不会在未知客户端上盲目调用。

枪械、贴纸、Demo 重写和创意工坊地图功能保持完整。五个贴纸逻辑槽仍可创建缺失字段、保留预设位置或改用自定义位置；滑轨、具体枪型轮廓、模型投影／逆投影和节流实时同步均保留。Demo rewriter 继续按包内实际字段载荷动态映射 `serialized_entities` 长度表，不写死字段数量。枪械涂装仍使用经济属性与引擎原生材质初始化路径；地图雷达继续在外部生成遮罩，再由当前 CS2 的 `resourcecompiler.exe` 编译为隔离缓存中的原生 VTEX。

本版同时完成一次不改变功能语义的性能整理：运行时按实体代际缓存 RTTI／类型分类，减少帧回调中的重复虚表与类名解析；独立控制面板缓存由不可变物品目录派生的选项列表，避免每帧重建大量枪皮、贴纸、手套和挂件 UI 数据。缓存会在目录或实体代际变化时失效，不会跨对象复用旧状态。

### 使用与升级

1. 完全退出 CS2 与 HLAE，避免旧 DLL 仍驻留内存。
2. 使用 HLAE `2.192.7`，以 `-insecure` 启动离线 Demo 环境。
3. 只加载一个语言版本：`Lyan_nskinz-v0.6.1-EN.dll` 或 `Lyan_nskinz-v0.6.1-zh-CN.dll`。
4. 修改枪械、刀、手套、贴纸或地图后点击“更新”。源槽位缺少现代贴纸字段、默认手套或原皮枪械需要补齐经济字段时，生成并加载一次“临时换肤 Demo”。
5. 游戏更新后若面板报告版本／指令窗不匹配，请停止使用相关模块并提交日志；不要绕过保护检查。

自动化验证证明发布 DLL 与当前文件布局、序列化和资源格式一致，但不能替代每个 Demo、视角、武器动作和工坊地图的画面验收。独立刀模链及无一一对应关系的地图烘焙几何仍属于逐场景验收范围。

## English notes

v0.6.1 rebases every client-address-dependent feature on the October 14, 2026 CS2 `2000932` build. The release relocates and verifies knife serialization, model assignment, material copy/generation, resource recollection, skeleton references, weapon-type animation graphs, arms lifecycle, stock-glove native refresh, the HUD consumer and entity roots. Every entry remains fail-closed behind the current PE timestamp, exact call targets and RIP-relative instruction windows.

Weapons, stickers, demo rewriting and Workshop maps retain the complete v0.6.0 feature set. All five logical sticker slots can still materialize absent legacy/modern attributes, use native presets or custom placement, and synchronize slider/canvas changes through the throttled live-preview path. The demo rewriter maps the `serialized_entities` length table to actual field-bearing commands instead of assuming a fixed count. Firearm finishes continue to use guarded Econ attributes and engine-owned material initialization. Radar alpha overlays remain externally prepared and are compiled into cache-isolated native VTEX resources by the installed CS2 compiler.

Runtime overhead is reduced without changing feature behavior. Entity RTTI/classification is cached per object generation, and the isolated control panel reuses immutable catalog-derived option lists instead of rebuilding thousands of UI entries each frame. Both caches invalidate when their source generation changes.

The full native suite passed against the installed build. All 16 compatibility-manifest patterns matched exactly once, strict knife/glove evidence passed, the current local catalog and all installed Workshop radar fixtures parsed, native radar VTEX compilation succeeded, and the weapon material evidence passed. Rendered output for a particular demo, animation and Workshop map remains an in-game acceptance boundary.
