# Security / 安全问题

## English

nSkinzCS2 is an offline HLAE demo tool. Do not use it on VAC-protected or online servers, and do not report methods intended to bypass anti-cheat systems.

For a memory-safety issue, accidental data exposure, or another security-sensitive defect, use GitHub's private vulnerability reporting when available:

<https://github.com/Lyan-edit/CS2-nskinz/security/advisories/new>

Please include the affected commit or release, Windows/CS2/HLAE versions, a minimal reproduction and sanitized logs. Do not attach Steam credentials, personal data, game files or payment information. Until a fix is available, avoid the affected feature and keep testing offline.

## 简体中文

nSkinzCS2 是离线 HLAE Demo 工具。请勿在 VAC 保护服务器或联机服务器中使用，也不要提交用于绕过反作弊系统的方法。

如果发现内存安全问题、意外数据暴露或其他敏感缺陷，请在条件允许时使用 GitHub 私密漏洞报告：

<https://github.com/Lyan-edit/CS2-nskinz/security/advisories/new>

请附上受影响的提交或版本、Windows/CS2/HLAE 版本、最小复现步骤和脱敏日志。不要上传 Steam 凭据、个人数据、游戏文件或收款信息。在修复发布前请避开受影响功能，并始终保持离线测试。
