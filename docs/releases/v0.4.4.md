# v0.4.4 — 原皮枪械换肤修复 / Stock weapon finish initialization

Release date / 发布日期：2026-08-31

## 简体中文

### 本次修复

- 修复原皮 AWP 选择“嘣”（BOOM，paint kit `174`）后仍显示无涂装的问题。用户已通过 DLL 面板进行 Demo 实测并确认成功。
- 修复位于普通枪械共用流程，不是仅对 AWP 的特判：原皮缺少涂装、种子、磨损属性时，使用引擎接口补齐；材质容器为空时执行首次材质生成，避免原有刷新循环直接跳过。
- 已有涂装仍走属性同步与目标材质刷新；不反复追加相同属性。取消时只撤销仍由本次修改持有的记录，实体销毁、重用或 Demo 跳转后不回写失效对象。
- 枪械单独更新只刷新目标物品。材质初始化失败后停止当前对象/外观的自动重试，直到手动“更新”或对象代际变化，避免轮询中持续重建。此机制不是“所有 Demo 均无卡顿”的保证。
- 保留 v0.4.3 的枪型兼容校验、新旧网格选择、第一人称枪身绑定，以及输入法/搜索隔离和单 DLL 加载方案。完整本机目录不删减。

### 范围与验证

- **画面验证：** 本次原皮 AWP → 嘣案例由用户确认成功。其他受支持枪型使用相同修复流程，但没有逐枪、逐涂装完成 Demo 画面验收。
- **自动化检查：** 9 个定向检查和 46 项完整原生回归通过。覆盖缺失属性初始化、重复应用不增长、撤销、失效实体拒绝、初始化失败与有限重试；读取实际客户端的函数绑定证据通过。原生构造/生成调用的回归使用测试替身，不等同于游戏实测。
- **目录：** 检查 34 种枪型、1,449 个合法枪型/涂装组合；保留 1,408 个武器涂装和 74 个手套涂装。目录兼容检查不等于所有组合都实测成功。
- **加载与文字：** 两个语言 DLL 的六项隔离加载检查、无窗口 ImGui/WARP 渲染与三次资源重建、PE 导入和中文文本检查通过；不是独立纯净 Windows 虚拟机认证。
- **版本隔离：** 直接发布本次已验证的中英 DLL，文件字节不变；源码基于已发布 v0.4.3，仅加入本次枪械修复、测试及说明。暂停中的独立刀模续作未混入。

## English

### Changes

- Fixed a stock AWP remaining unpainted after selecting BOOM (`174`). The user confirmed the result in a demo using the DLL panel.
- The fix is shared by supported firearms, not an AWP-only special case. Missing paint/seed/wear records are constructed through the engine, and empty material owners receive their initial material generation instead of being skipped by the existing refresh loop.
- Existing attributes remain synchronized without repeated record allocation. Rollback removes only records still owned by this change; stale objects after destruction, reuse or seeking are not written back.
- Gun-only updates refresh the requested item. Failed initialization is latched for the current object/appearance until a manual Update or object-generation change, avoiding continuous polling retries. This is not a promise of stutter-free playback in every demo.
- Retained v0.4.3 weapon/paint compatibility, modern/legacy mesh and first-person HUD fixes, isolated IME/search input and single-DLL loading. The complete installed catalog is preserved.

### Validation and boundaries

- The stock AWP → BOOM case is user-confirmed. Other supported firearms share the implementation but have not each been visually tested with every finish.
- Nine targeted checks and all 46 native regression entries passed, covering initialization, no-growth repetition, rollback, stale identity rejection and bounded failure retries. Actual-client read-only binding checks passed. Engine calls in regression fixtures are simulated, not gameplay acceptance.
- Catalog validation covers 34 firearms and 1,449 compatible pairs, retaining 1,408 weapon and 74 glove finishes. Compatibility metadata is not visual certification of every combination.
- Both language DLLs passed six isolated loader cases and offscreen ImGui/WARP rendering with three resource recreations, plus import and Chinese text checks. These are local isolation tests, not an independent clean-Windows VM certification.
- The exact tested DLL bytes are published. Product source is the published v0.4.3 baseline plus this firearm fix and its tests; paused independent knife-model continuation is excluded.

### Compatibility and installation

Windows 10/11 x64; HLAE **2.191.1** development/compatibility baseline; CS2 Steam Build **25000182**, Client/Server **2000899**, Patch **1.41.7.8**, Source revision **10948930** (2026-08-28). The client's SHA-256 is listed in the table above. The friend's HLAE binary version was not independently verified.

No additional VC++ redistributable, DirectX SDK, .NET, Python or compiler installation is required to use the DLL. Static MSVC `/MT` and embedded precompiled UI shaders are retained. Build tools are required only when compiling the source.

**HLAE `-insecure` offline demos only. Never use on VAC-protected or online servers.** Future game updates may change required layouts.

Choose one language DLL from the assets, extract it into a writable folder, fully restart CS2 via HLAE, and use its actual full path:

```text
mirv_loadlibrary "D:/nSkinzCS2.dll"
```

Use `nSkinzCS2.zh-CN.dll` for Chinese. Do not load multiple versions/languages together. Use exactly one pair of ASCII quotes. Configure the XUID, weapon and compatible finish through the panel, then click Update. Config/catalog/log sidecars are generated automatically.

### Known limitations

Knife model/animation replacement and stale vanilla knife materials are not fixed here. Knives/gloves do not use the new firearm initialization entry. Creating missing sticker attributes or keychain modules is outside this fix and those requests may still be rejected. No exhaustive demo/finish/machine/FPS guarantee is made. Include the DLL language/hash, CS2 Build ID, HLAE version, steps and redacted logs when reporting issues.
