# nSkinzCS2 v0.6.4 — Keychains through Temporary Demo reconstruction

Release date / 发布日期：2026-10-26

## 中文说明

挂件替换、新增和清除统一改为“临时换肤 Demo”重建。设置 XUID、枪型和挂件后，点击“生成并加载临时 Demo”；只点“更新”不会实时更换挂件。原始 Demo 不覆盖。

- 已有挂件换款默认保留原位置、seed 和附加属性；“无挂件（移除）”与“不修改”分别处理。
- 无挂件武器写入对应枪型的挂件属性，起始位置取自 34 种本机枪械模型中显式标记的 `DefaultLocation` 区域；现代与 legacy 模型分别处理。
- 挂件 ID、seed 等整数属性按联合体原始 32 位写入；挂件可以单独生成任务，与枪皮／贴纸共同重写时协调属性向量扩容，不覆盖其它饰品数据。
- 每个独立创建记录、完整跳转快照和必要的后续更新均处理，输出后逐记录验证。不同玩家配置若要求同一物理枪械永久写入矛盾挂件，会明确报错。
- 注入端关闭挂件实时写入、模型刷新、模块创建和挂件专用实体扫描。默认 T／CT 手套继续严格使用临时 Demo 重建，生成 Demo 中的手套保持只读。

### 卡顿相关整理

历史日志记录过实体工厂阶段约 327–335 ms 的长帧。空闲工厂和生成 Demo 的工厂帧回调现在会在读取整份配置之前返回，减少帧率频次的配置复制；外置重写进程使用低于正常的 CPU 优先级。挂件也不再通过播放时持续扫描／覆盖来维持效果。

这是对明确多余工作的移除。**本轮尚无新 DLL 的游戏内帧时间对比，不声称已解决全部卡顿。** 新增挂件的 CS2 原生模块生成与最终画面也仍需实机验收；下列测试验证的是序列化、独立跳转、其它属性保留及 DLL 加载／离屏渲染。

### 验证

- 四份独立原始录制，1,317 把目标枪械、506,431 条挂件记录、3,106 个独立 Created；清除阶段再次验证相同规模，另有 202 次独立正反向跳转检查。
- 检查原有枪皮、贴纸、品质、名称和已有挂件位置／seed 保留。
- g161 混合请求：5 把枪的涂装、25 个缺失贴纸槽、10 把枪的挂件及分别配置的 T／CT 手套；挂件 4,314 条记录／15 个 Created，手套 97,791 条记录／29 个 Created，均通过。
- Rust 18 项常规测试与上述真实录制挂件矩阵、完整 C++ 回归通过；包括 37 个已安装工坊地图条目和实际雷达资源编译。双语发行 DLL 通过 6 项隔离加载、便携依赖与中文文本检查、WARP FL10.0 离屏像素读回和 3 次重建。

详情见[实现与回归记录](../development/keychain-temporary-demo-20261026.md)。

### 升级与使用

1. 退出 CS2／HLAE，保留需要的配置；重新启动后只加载一个语言版本的 v0.6.4 DLL。
2. 打开原始 Demo，填写该录制内目标玩家的 XUID、枪型和挂件，勾选启用。
3. 点击“生成并加载临时 Demo”。后续换款／清除也重新生成；旧临时文件不会因更换 DLL 自动改变。
4. 对比同一玩家、枪型和 tick 的效果。测试已有挂件时请选择与原挂件不同的款式。

兼容基线延续 v0.6.3：CS2 Client/Server `2000935`、Patch `1.41.9.2`、Steam Build `26144732`；HLAE `2.192.8`／AfxHookSource2 `0.41.8`。保留枪皮、刀、手套、五槽贴纸及工坊地图／雷达功能。本版不声称适配新的游戏客户端更新。

## English notes

Keychain replacement, addition and explicit removal now use Temporary Demo reconstruction exclusively. Configure XUID, firearm and keychain, then select **Generate and load temporary demo**. Update alone does not change a live keychain. The original recording is preserved.

Existing placement, seed and auxiliary attributes are retained. Missing keychains receive attributes and a starting mount derived from the corresponding model's marked DefaultLocation region; the table covers 34 firearm definitions and modern/legacy variants. Integer attributes preserve their raw union bits. Keychain-only requests do not synthesize paint, sticker, quality or name changes. Conflicting permanent requests for the same physical weapon fail explicitly.

Every independent Created/full-packet snapshot and necessary subsequent attribute update is handled and verified. Live keychain writes, model refresh, module factories and keychain-only scans are disabled. Default T/CT glove reconstruction and read-only generated-Demo glove behavior remain intact.

Idle/generated-Demo factory callbacks now exit before copying configuration, and the external rewriter runs at below-normal CPU priority. Historical logs showed 327–335 ms factory spikes; **no new gameplay frame-time benchmark or rendered keychain acceptance was performed**, so this is not a claim to eliminate every stutter or visually certify every added keychain.

Regression passed four independent recordings: 1,317 weapon handles, 506,431 target records, 3,106 Created snapshots, the same coverage again for removal, and 202 independent forward/backward seek checks with unrelated cosmetics preserved. A mixed firearm/five-sticker/keychain/T-CT-glove request, 18 regular Rust tests and the full native C++ suite also passed. Both language DLLs pass six isolated loader cases, portable-import/text checks and the offscreen WARP rendering gate.

Restart CS2/HLAE, load one language DLL, open the original recording and regenerate the Temporary Demo after configuring keychains. The compatibility baseline remains CS2 `2000935` / Patch `1.41.9.2` / Steam Build `26144732`, HLAE `2.192.8` / AfxHookSource2 `0.41.8`.
