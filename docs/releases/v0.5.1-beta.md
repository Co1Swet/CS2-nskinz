# v0.5.1 Beta — 创意工坊地图模型替换 / Workshop map-model replacement

Release date / 发布日期：2026-09-20

## 简体中文

### 定位

v0.5.1 Beta 将创意工坊地图及地图模型替换正式纳入 HLAE 离线 Demo 工作流。枪械皮肤继续沿用旧实现路径；刀模／动作和默认 T/CT 手套保留当前测试实现。DLL 在第一次 Demo 加载期间接收配置，并在第二次加载同一 Demo 时替换地图协议数据，不改写 `.dem` 或创意工坊文件。

### 地图与模型替换

- “地图更换”页自动读取 Steam 本地创意工坊清单，识别已安装订阅及顶层 `maps/<name>.vpk`。
- 运行时原子化安装 Demo protobuf、KeyValues、manifest 和缺失模型资源链；任何必需签名缺失或不唯一时整体失败关闭。
- 对确认属于原地图的生成模型实施安全抑制，减少原始地图与目标地图模型叠加、悬空和穿模。
- 雷达背景透明度处理随当前目标地图重新应用；雷达边缘像素、多层道路图和特殊地图素材仍需逐地图验收。
- 不再提供会触发 `3dskybox_*.vpk Failed to load file (missing)` 致命错误或导致 Demo 卡加载的 VPK 硬屏蔽／重定向实验。
- 已经烘焙进编译地图且没有安全一一对应模型的几何体，仍可能保留；本测试版不承诺任意两张地图之间完全无残留。

### MulNX 与开源许可

地图更换运行时行为移植并逐项核对自 [`Co1Swet/MulNX_CS2`](https://github.com/Co1Swet/MulNX_CS2) 提交 `361008b208326d9e7916ff2cd58dd57a0492c400`（2026-09-16）。本项目不包含或调用 MulNX 文件改写器，但具体 hook、消息字段、寄存器和资源回退行为属于适配／衍生范围。

因此 v0.5.1 Beta 的源码与 DLL 按 `AGPL-3.0-only` 发布。附件和源码树包含：

- `third_party/` 内 Dear ImGui、MinHook 与 nlohmann/json 的各自许可声明。

### 使用地图替换

1. 订阅并完整下载目标 CS2 创意工坊地图。
2. 第一次加载原 Demo，并用 `mirv_loadlibrary` 加载 v0.5.1 Beta。
3. 打开“地图更换”，重新识别已订阅地图，选择目标，启用替换并点击“使用选中的创意工坊地图”。
4. “原始 Demo 地图”可以留空自动识别；点击主界面“更新”，确认日志出现 `Map remap ready` 和 `Map remap armed`。
5. 再次 `playdemo` 加载同一个 Demo。地图及可安全替换的地图模型会在第二次解析中处理。

**只用于 HLAE `-insecure` 离线 Demo。禁止用于 VAC 保护或任何在线服务器。**

## English

v0.5.1 Beta releases Workshop map and map-model replacement as an HLAE offline-demo beta feature. It discovers installed Workshop subscriptions, arms the target during the first load, and applies the protocol/resource substitutions while the same demo is loaded a second time. It never rewrites the `.dem` or Workshop package.

Safe generated models belonging to the source map are suppressed. Geometry baked into the compiled source map can remain when no safe one-to-one replacement exists. The experimental skybox VPK hard block/redirect is excluded because it produced a fatal missing-VPK error or stalled demo loading.

The map-remap behavior is adapted from MulNX_CS2 commit `361008b208326d9e7916ff2cd58dd57a0492c400`. v0.5.1 Beta is distributed under `AGPL-3.0-only` with the full license, provenance/change notice and complete Corresponding Source for the DLLs. The MulNX file rewriter is not included.

Compatibility is limited to Windows x64, HLAE 2.192.2.0 and the checked CS2 baseline above. Firearm finishes retain the previous implementation path. Knife actions, stock gloves, radar edge pixels and map-specific baked geometry remain rendered-acceptance limitations.
