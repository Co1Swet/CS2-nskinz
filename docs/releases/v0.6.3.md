# nSkinzCS2 v0.6.3 — Default T/CT glove reconstruction across Demos

Release date / 发布日期：2026-10-25

## 中文说明

本版修复默认 T／CT 手套在临时 Demo 返回成功后，实际载入、跳转或快照恢复时仍显示原皮的问题。旧代码按 Pawn handle 和队伍缓存“已补齐字段”，随后把独立 Created／完整快照也跳过了；顺序解析曾出现正确值便算通过，因此漏掉跳转所用快照里的默认零值。

现在每个独立创建记录都会完整写入手套定义、品质、身份、涂装属性、变更计数及两组 bodygroup；如果创建时尚未出现 T／CT 队伍字段，会在首次可确定队伍的更新包中补齐。代码从各 Demo 自带的序列化定义解析字段，不依赖特定 Demo、玩家或 Pawn handle。

输出后会逐记录检查目标手套的全部请求字段，并额外读取顺序解析通常跳过的完整快照。缺失或不匹配会报告具体 tick、事件、handle 和字段；日志新增 `verified_glove_records`、`verified_glove_created` 计数。

默认 `0 / 5028 / 5029` 手套、尚未读明的载体及所有生成 Demo 中的手套，在注入端严格只读。字段不匹配时要求重新生成临时 Demo，不会进入实时 Econ 字段写入、原生模型刷新或 Wearable 创建路径。

### 升级方法

1. 退出 CS2／HLAE，避免旧 DLL 继续驻留。
2. 加载一个语言版本的 v0.6.3 DLL，保留需要的原有配置。
3. 打开原始 Demo，选中该 Demo 内的目标玩家并应用配置。
4. 重新生成并加载临时 Demo。旧版本生成的文件不会因更换 DLL 自动修好；修改重建手套配置后也需重新生成。

兼容基线延续 v0.6.2：CS2 Client/Server `2000935`、Patch `1.41.9.2`、Steam Build `26144732`；HLAE `2.192.8`／AfxHookSource2 `0.41.8`。现有刀型、枪皮、五槽贴纸、自定义位置预览和工坊地图／雷达功能保留。本版不声称适配了新的游戏客户端更新。

## English notes

v0.6.3 repairs default T/CT gloves that disappear when loading or seeking an otherwise successfully rewritten Temporary Demo. The previous Pawn/team cache also deduplicated independent Created/full-packet records, leaving their glove fields at the source defaults. A linear-only verifier missed those checkpoints.

Each independent Created record now materializes the complete glove state. Late team assignment is handled by the first update where a T/CT rule resolves. Verification checks every requested glove field across entity records and full snapshots, reporting the exact tick and field on failure. Default, unknown and generated-Demo glove carriers are strictly read-only at runtime; mismatches require another Temporary Demo rather than live field writes, native refresh or Wearable creation.

Cross-Demo regression passed four independent recordings: 24 default-glove player/recording combinations, 1,894,511 target records, 702 Created snapshots and 132 independent forward/backward seek readbacks. Every recording covers both teams. The known bad output is rejected at tick 3841; different T/CT cosmetics also pass. Fifteen regular Rust tests, two actual-file regressions and the full native C++ suite passed. Rendered gameplay remains an in-game acceptance check.

Restart CS2/HLAE, load only one v0.6.3 language DLL, select the target player in the original Demo and regenerate the Temporary Demo. Existing generated files retain their old snapshots.

The compatibility baseline remains CS2 `2000935` / Patch `1.41.9.2` / Steam Build `26144732`, HLAE `2.192.8` / AfxHookSource2 `0.41.8`. Existing knife, firearm, sticker and Workshop-map features are retained.
