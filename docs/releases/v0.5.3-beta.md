### 雷达修复

- “黑底容差”现在是自动暗底检测的真实双向偏移，不再被自动阈值强制抬高；降低它会保留更多深色道路，提高它才会删除更多黑底。
- 旧版容易误删道路的 `24 / 4` 默认值迁移为 `12 / 12`；“暗色道路恢复半径”上限扩大到 32 像素，且只恢复被可信道路边界包住的缺口。
- 每组参数现在生成独立的内容寻址雷达资源名，避免 CS2 继续显示旧滑块参数对应的缓存纹理。
- `de_inferno_water` 真实纹理回归中，关闭暗路恢复时保留 160,676 像素，新默认值保留 174,449 像素，补回 14,385 个受边界约束的暗色道路像素。
- 日志会记录 `black_tolerance`、`applied_black_tolerance`、`neutral_mode`与灰阶样本数，用于追踪不同创意工坊地图。

### 验证与限制

- Release x64 全量原生回归通过；中英文 DLL 通过独立 x64 `LoadLibraryW`、UI 导出、CRT 线程回调及卸载检查。
- 真实本机创意工坊回归覆盖 Ancient Night、Nirage、Nuke Rainy、Mirage Water、Dust2 Water、Inferno Water 与 All-in-One。
- 更新 DLL 后必须完全重启 HLAE/CS2，重新选择地图并二次加载 Demo；旧版 v6 的雷达默认配置会自动迁移到 v7。
- 具体创意工坊纹理仍可能存在独特配色或多层雷达，需要在游戏画面中验收。

## English notes

v0.5.3 Beta fixes opaque grid/matte residue, black edge pixels and over-deleted dark roads in Workshop radar overlays. The CS2 baseline remains 2000918 and the HLAE baseline is updated to 2.192.6 / AfxHookSource2 0.41.6.

Black tolerance is now a real signed correction to automatic matte detection. Defaults migrate from the destructive `24 / 4` pair to road-preserving `12 / 12`; bounded dark-road recovery supports up to 32 pixels. Every parameter result uses a content-addressed resource alias so a regenerated overlay cannot silently reuse the previous compiled name. On the installed `de_inferno_water` regression texture the new default retains 174,449 pixels versus 160,676 with recovery disabled and restores 14,385 bounded dark-road pixels.

The full native suite, installed-CS2 compatibility scan, real installed-Workshop radar cases and isolated loading checks pass. Actual map rendering remains an in-game acceptance boundary, and HLAE/CS2 must be fully restarted to clear an already loaded DLL and Panorama texture cache.

The map-remap portion remains adapted/derived from AGPL-3.0 MulNX_CS2 as documented above. This release includes the complete Corresponding Source, license, provenance and modification notices and does not include or invoke the MulNX file rewriter.
