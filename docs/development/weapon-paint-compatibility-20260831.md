# 枪械涂装兼容性校验 — 2026-08-31

范围：修复枪械面板使用全局涂装列表、允许错误枪型/涂装组合的问题。保留此前 M4A4 新旧网格和 render-only HUD 修复，不改独立刀模型、刀涂装、手套或挂件规则。

## 实现

- 目录从本地 `items_game.txt` 的所有 `item_sets`、`client_loot_lists` 重复段读取精确 `[paint_internal_name]weapon_internal_name` 组合，再用 `items` 和 `paint_kits` 映射数字 ID。不会按中文显示名称、涂装名称前缀或新旧模型推断兼容性。
- `Catalog::weapon_paint_compatibility` 保存武器 definition → 排序去重的涂装 ID 数组。共享涂装可对应多种枪，不合并 M4A4（16）和 M4A1-S（60）。完整 `weapon_paint_kits` 不删减。
- 兼容关系随目录 IPC 快照保存/加载。旧快照缺字段、目录加载失败或枪型缺数据时状态为 Unknown，不代表任意涂装都可用。
- 枪械面板只显示兼容项，并显示可用数量；搜索沿用现有 UTF-8 路径。`-（不修改）` 和 `原皮／无涂装` 始终保留。两者仍通过已有意图区分，不改变 paint=0 的语义。
- 切换枪型、加载旧配置后若原涂装不兼容，面板保留原 ID 和名称，显示“不可用”和解释。不会自动清空成原皮、假装显示为 `-`、或自动替换成另一种皮肤。
- 三个运行时入口使用同一校验：标准枪械外观管线（绑定/预缓存/挂件操作前）、实体应用路径（缓存成功分支前）、底层 econ 写入（属性写入前）。按真实武器 definition 校验，不仅相信面板所选枪型；不兼容或 Unknown 时拒绝应用并记录限次诊断。
- 没有新增逐帧材质重建、游戏线程等待或 SetModel 调用。完整刀模暂停点仍在 [knife-model-checkpoint-20260831.md](knife-model-checkpoint-20260831.md)。

## 数据与后台验证

基线：CS2 ClientVersion **2000899** / Patch **1.41.7.8** / Steam Build **25000182**；HLAE 开发基线 **2.191.1**。游戏目录测试使用此前从本机该基线提取的原始文件，不依赖网络皮肤数据库。

- 34 种受支持枪械均有兼容记录，共 **1,449** 个不同的枪型/涂装组合。
- 完整武器涂装目录仍为 **1,408** 项，手套涂装仍为 **74** 项。组合数不等于不同涂装数：共享涂装会出现在多个枪型上，完整目录也包含刀涂装。
- AK-47 61 项、M4A4 52 项、M4A1-S 46 项、USP-S 45 项（不含“不修改”和“原皮”）。
- 真实数据验证 M4A4 皇帝 844 与破浪狂飙 1353 同时可选，M4A1-S 不接受这两个 ID；USP-S 倒吊人 1040 保留；AK-47 和 FN57 共享淬火 44 保留。
- 8 个定向测试入口通过：覆盖重复段合并、共享映射、精确名称区分、评论/错误平台/未知引用排除、IPC 新旧格式、中文名称、非法 ID、缺失目录、原皮与不修改、实际生产入口的写入前拦截，以及原有网格/HUD 回归。
- 中英 DLL 编译成功；6 个隔离 LoadLibrary 测试及无窗口 WARP 内嵌 DXBC 渲染检查通过。保持 `/MT`，未引入 VC++ 或 D3DCompiler 可再发行运行库依赖。

完整回归及 DLL 哈希见 `build/paint-compat-fix/VALIDATION.md`。

## 交付与边界

- 中文：`build/paint-compat-fix/zh-CN/nSkinzCS2.zh-CN.dll`
- 英文：`build/paint-compat-fix/en/nSkinzCS2.dll`
- 正式 `build/Release`、GitHub 标签和 Release 均未修改。
- 本轮未启动 CS2、注入游戏或操控桌面。这是目录、运行时入口和隔离加载验证，不是 1,449 个组合的游戏内视觉认证。
- 兼容列表表示游戏文件定义的合法组合，不保证材质刷新、HUD 生命周期等其它路径完全无缺陷。本轮未扩大修改此前审查发现的 HUD 缺失成功条件和刷新缓存生命周期问题。

使用时先退出加载旧 DLL 的 CS2，重新通过 HLAE `-insecure` 离线 Demo 加载新 DLL。面板换到 AK 时不应出现皇帝，换到 M4A4 时应能搜索到皇帝和破浪狂飙；如导入 AK+844 的旧配置，应显示不可用并拒绝应用，不应变原皮。枪械原皮、共享涂装以及原有合法配置应继续正常使用，画面需在 Demo 中另行复测。
